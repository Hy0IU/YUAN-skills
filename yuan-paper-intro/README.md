# yuan-paper-intro

面向尚未读过论文的读者，快速讲清模型从输入到预测的具体流程。重点是模块方法，不展开实验总结或研究评价。

输出依次包含中文译名标题、期刊或会议信息、原文模型框架图、研究侧重、整体流程、逐模块步骤和最终预测。关键公式配文字解释，采用 Obsidian 兼容的 `$...$` 与 `$$...$$` 格式。

- **输入**：论文 PDF，可指定输出目录。
- **输出**：以 PDF 正文中识别到的完整原文标题命名的 Markdown，以及使用同一主名的框架图图片。适用于 Zotero 导出的附件或任意文件名的上传 PDF；文档内一级标题仍使用中文译名。用户可明确指定输出文件名。
- **入口**：[SKILL.md](SKILL.md)。
- **示例请求**：使用 `$yuan-paper-intro` 说明这篇论文的模型结构和运行流程。
