# 文档结构参考

使用下面的简洁结构。替换所有占位内容；主要模块按论文实际组织增减。模块内部可按关键步骤分小节，不要求固定字段或固定数量。

文档开头固定为“中文译名一级标题 → 发表信息列表 → 原文框架图”。中文标题不改变输出文件名。发表信息从以下两种格式中按实际类型选一，不同时输出期刊与会议字段；填写核实后的事实和来源，未知项按 SKILL.md 注明状态，不能填入猜测值。

期刊格式：

```markdown
- **期刊名称**：*{{期刊正式名称}}*（{{缩写}}），发表时间：{{YYYY 年 M 月及必要的日期类型}}。[来源]({{链接}})
- **期刊等级**：JCR **{{Q1/Q2/Q3/Q4}}**（*{{学科类别}}*，{{发布年份}} 年发布）；中科院 **{{分区}} 区**（大类：{{名称}}；小类：{{名称及分区}}，**{{年份}} 年分区版**）。[来源]({{链接}})
- **影响因子**：**{{JIF 数值}}**（{{指标年份}} 年 JIF，{{发布年份}} 年发布）。[来源]({{链接}})
- **是否开源**：**{{是／否／尚未公开／未查到公开代码}}**{{必要的日期或状态说明}}。[代码或说明]({{链接}})
```

会议格式：

```markdown
- **会议名称**：{{对应届次的正式会议名称}}（{{缩写及年份}}）。[来源]({{链接}})
- **会议级别**：**CCF {{A/B/C}} 类**（{{年份或版本}} 年目录）{{有依据时补充顶会等描述}}。[来源]({{链接}})
- **是否开源**：**{{是／否／尚未公开／未查到公开代码}}**{{必要的日期或状态说明}}。[代码或说明]({{链接}})
```

多学科分区按核实结果注明类别；仅有公开转引时注明“公开转引”；未收录、预印本、未核实或没有可用链接时，直接写实际状态，移除不适用的占位项或链接。不要用英文原题或模型名称单独替代中文译名标题。

实际文档采用 Obsidian 数学分隔符：行内用 `$...$`，块级用独立两行的 `$$`。下面的格式示例用代码块展示源码，生成文档中的实际公式应去掉外层代码围栏，让公式直接渲染。

```markdown
门控权重为 $g$，两路表示为 $h_A$ 与 $h_B$，逐元素融合如下：

$$
h=g\odot h_A+(1-g)\odot h_B.
$$

其中 $\odot$ 表示逐元素乘法。
```

局部表达深度可参考以下通用示意，不将它预设为任何论文的真实操作：

> 对当前候选，先计算它与每个历史位置之间的距离，得到一组数值；在历史位置上求平均，得到一个标量。把该标量送入论文定义的编码函数，得到距离向量，再与当前候选的表示拼接。换成另一个候选时，这组距离及其汇总结果也会变化。

这样的说明应明确“对谁计算、沿哪个对象集合汇总、是否先编码、结果用于哪里”。实际操作、顺序和候选依赖均以当前论文为准。
